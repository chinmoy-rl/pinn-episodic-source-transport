# pinn-episodic-source-transport

Code for the manuscript

> **Physics-informed neural networks for solute transport in porous media with an episodic source: error sources and identification of switching times**
> M. K. Singh, C. Roy Laskar. Submitted to *Computers & Geosciences*.

The code solves the one-dimensional advection–dispersion–reaction equation with an intermittent (episodic) inlet source using physics-informed neural networks (PINNs). It compares seven PINN variants over three Péclet regimes and twenty random seeds, and it recovers the source reactivation time from noisy downstream observations (inverse problem). All data are synthetic and are generated by the code itself; no external data files are needed.

## Requirements

- Python 3.10 or later
- JAX, Optax, NumPy, mpmath, Matplotlib

```bash
pip install -r requirements.txt
```

A GPU is recommended for the full study. Everything also runs on a CPU, only more slowly.

## Files

| File | Purpose |
|---|---|
| `params.py` | All physical, numerical and training parameters used in the study |
| `reference.py` | Reference solutions: stabilised Laplace-domain solution (de Hoog inversion) and explicit finite-difference scheme with a second-order ghost-node outlet |
| `pinn.py` | The seven PINN variants (JAX), trained for all seeds at once with `vmap` |
| `train.py` | Forward-study driver: job list, parameter sweeps, checkpointing and resume |
| `inverse.py` | Inverse problem: recovery of the reactivation time `T_off` from noisy wells |
| `analyze.py` | Builds every table and figure from the saved results |

## Quick test

This short run checks the installation and exercises every stage on a small synthetic test case (2 seeds, 300 epochs, one forward job and one inverse job). It takes about 3–4 minutes on a laptop CPU.

```bash
python analyze.py --stage reference                         # about 1 min
python train.py --smoke --variants base --pe 2.0            # about 1 min
python inverse.py --smoke --workers 11 --worker 0           # about 1 min, one inverse job
python analyze.py --stage pinn
python analyze.py --stage inverse
```

Expected behaviour:

- The first command prints the grid-convergence table. These numbers are deterministic and must match Table 2 of the manuscript exactly, for example, at `Pe=10.0 Nx=800` the relative L2 error is `3.404e-06` with order `2.00`.
- The smoke runs finish with `[done ]` lines and write `results/pinn_base_pe2.0.npz` and `results_inverse/inv_pe2.0_near_n0.npz`.
- Figures appear in `out/figures/` and tables in `out/tables/`.
- With only 300 epochs the networks are far from converged, so the PINN errors and the recovered `T_off` are much worse than in the paper. Smoke results are for testing only.

## Reproducing the results

Run the steps in order from the repository folder.

```bash
# 1. Reference solutions and grid convergence (Table 2, Figs 2-3)
python analyze.py --stage reference

# 2. Forward study: 7 variants x 3 Peclet numbers, beta_w sweep,
#    lift study and inlet-ramp study (20 seeds each)
python train.py --sweep all

# 3. Inverse problem: switching-time identification
python inverse.py

# 4. Tables and figures
python analyze.py --stage pinn
python analyze.py --stage corner
python analyze.py --stage inverse
```

Step 1 must be run before step 3, because the inverse problem reads the cached reference solution.

Typical run times on a single GPU: about 17 minutes per forward job (20 seeds, 60 000 epochs) and about 10 minutes per inverse job (20 seeds, 30 000 epochs). The full study has 42 forward jobs and 11 inverse jobs, so it takes roughly 14 hours when the jobs are run one after another. Jobs can be split across several processes or machines with `--workers` and `--worker` (see below).

## User guide

### Inputs: `params.py`

All settings are in `params.py`; no other input files are used. The main groups are:

| Group | Parameters | Meaning |
|---|---|---|
| Transport | `R`, `DA`, `PE_LIST` | Retardation factor, Damköhler number, Péclet numbers studied (0.5, 2, 10) |
| Source | `U0`, `H`, `TON`, `TOFF`, `T_END` | Source strength and decay rate, switch-off time, reactivation time, final time |
| Inlet ramp | `RAMP_TAU`, `RAMP_SWEEP` | Optional smooth start of the source (0 in the main study) |
| Reference solution | `NX_REF`, `NX_LADDER`, `DT_SAFETY` | Finite-difference grid and stability safety factor |
| Evaluation | `NX_EVAL`, `NT_EVAL`, `DELTA_SWITCH`, `CORNER_RADIUS` | Evaluation grid and the switching-window and corner regions used for the error measures |
| Network and training | `LAYERS`, `EPOCHS`, `LR`, `LR_DECAY_AT`, `N_F`, `N_IC`, `N_BC`, `SEEDS` | Network size, training length, learning rate and its decay, numbers of collocation points, random seeds |
| Variant settings | `N_F_FOCUS`, `BETA_W`, `SIGMA_T`, `RD_*`, `CAUSAL_*`, `DD_INTERFACE`, `HC_*` | Settings for each PINN variant |
| Inverse problem | `INV_*` | Epochs, initial guess for `T_off`, smoothing schedule, well layouts, noise levels |

Changing a physical parameter changes the stored signature, and old results and cached reference fields are then recomputed instead of reused.

### Command-line options

`train.py`

| Option | Meaning |
|---|---|
| `--sweep {main,betaw,lift,corner,all}` | Which set of jobs to run (default `main`) |
| `--variants base,pw,...` | Run only these variants |
| `--pe 0.5,2.0` | Run only these Péclet numbers |
| `--epochs N`, `--seeds N` | Override the number of epochs or seeds |
| `--workers N --worker i` | Split the job list into N parts and run part i |
| `--save-every N` | Checkpoint interval in epochs (default 1000) |
| `--force` | Retrain even if a result file exists |
| `--smoke` | Quick test: 300 epochs, 2 seeds |
| `--list` | Show the job list and exit |

`inverse.py` accepts `--epochs`, `--seeds`, `--workers`, `--worker`, `--save-every`, `--force`, `--smoke` and `--list` with the same meaning.

`analyze.py --stage {reference,pinn,corner,inverse,all}` selects which tables and figures to build.

### Outputs

| Folder | Contents |
|---|---|
| `cache/` | Reference solutions on the evaluation grid (`fdm_pe<Pe>.npz`) |
| `results/` | One file per forward job, `pinn_<variant>[_<tag>]_pe<Pe>.npz`: predicted field and PDE residual for every seed, training time, parameter count and loss history |
| `results_inverse/` | One file per inverse job, `inv_pe<Pe>_<wells>_n<noise>.npz`: recovered `T_off` for every seed, field error and convergence history |
| `out/tables/` | LaTeX tables (`.tex`), full statistics (`.json`) and `inserts.json` with the key numbers quoted in the text |
| `out/figures/` | All figures as PDF |

Training writes a checkpoint every 1000 epochs. An interrupted job resumes from its last checkpoint, and finished jobs are skipped.
